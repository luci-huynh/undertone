Hides on any mouse down elsewhere, scroll, app activation, after 4 s, and when ⌥T fires. A read that finishes after a newer mouse event is discarded.
- Deviation from the option text: “hides when typing” is **not** implemented, because it would need a global keyboard monitor (runbook S24: no keylogger); the button disappears within 4 s instead.
